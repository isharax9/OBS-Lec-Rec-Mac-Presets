# OBS Lecture Recording Mac Presets

This repository contains custom OBS (Open Broadcaster Software) presets specifically designed for lecture recording on macOS. These presets are optimized for high-quality audio and video, making it easier to set up and start recording your lectures or presentations.

## How to Import These Presets to OBS

Follow these steps to import the presets into OBS on macOS:

### 1. Prerequisites

Ensure you have OBS installed on your Mac. If you don't have it yet, you can download it from the official OBS website: [https://obsproject.com/](https://obsproject.com/).

### 2. Download the Presets

1. Clone the repository or download it as a ZIP file:
   - To clone:
     ```bash
     git clone https://github.com/isharax9/OBS-Lec-Rec-Mac-Presets.git
     ```
   - To download as a ZIP:
     - Click on the green **Code** button in the repository.
     - Select **Download ZIP** and extract the contents.

2. Locate the preset files in the repository.

### 3. Open OBS and Access Settings

1. Launch OBS on your Mac.
2. Navigate to **Scene Collection** (top menu bar) > **Import**.

### 4. Import the Presets

1. In the **Import Scene Collection** dialog that opens:
   - Browse to the folder where you've downloaded/extracted the presets.
   - Select the appropriate `.json` file for the preset you'd like to use.
2. Click **Open** to import the preset.

### 5. Activate the Preset

1. After importing, go to **Scene Collection** again.
2. Select the newly imported preset from the list to activate it.

### 6. Customize (Optional)

You can customize the imported settings as per your preferences. Some areas you might want to adjust:
- **Audio Input**: Ensure your microphone is selected in **Settings > Audio**.
- **Video Resolution**: Check that the output resolution matches your requirements in **Settings > Video**.

### 7. Start Recording

Once the presets are imported and configured, you're ready to start recording! Press the **Start Recording** button in OBS to begin.

---

## Troubleshooting

If you encounter any issues while importing or using the presets:
- Ensure you have the latest version of OBS installed.
- Verify that the `.json` preset file is not corrupted.
- Restart OBS after importing the presets.

For further assistance, feel free to open an issue in this repository.
